# Versioning Model

## Public GitHub Releases

This repository uses the `v0.x` version line for all public GitHub releases, tags, release notes, and portfolio-facing documentation.

Public releases include:

- v0.4 — Security Hardening
- v0.4.1 — Public Security Polish
- v0.4.2 — Doctor Output Consistency
- v0.5 — Public Toolkit Foundation
- v0.5.1 — Public Toolkit Alignment
- v0.5.2 - Public Quality Gate
- v0.5.3 - Contract Enforcement
- v0.6.0 - Agent-Ready

## Current Public Release

**v0.6.0 - Agent-Ready**

v0.6.0 is the current public release. It adds public-safe runtime reporting, machine-readable JSON output, consistent CLI help and version contracts, blocking Bats regression tests, and sanitized demo-output contract enforcement while preserving established behavior and the public/private boundary.

## Internal Documentation

Private HomeLab documentation may use separate internal milestone labels. Those labels are not public GitHub release versions and do not define the public release track.

## Historical Sanitized Exports

Historical sanitized exports are preserved in Git history and archival branches, not in the canonical `main` tree.

Historical export names do not override or replace the public GitHub `v0.x` version line.
