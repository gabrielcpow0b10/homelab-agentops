## Maintenance policy

Future cleanup should follow the same pattern:

1. Validate the release or milestone first.
2. Audit branch ancestry before deletion.
3. Preserve protected branches and release tags.
4. Keep recovery records outside the public repository.
5. Re-run strict security and canonical quality validation after cleanup.

This keeps HomeLab AgentOps public-safe, recoverable, and ready for the next milestone.
